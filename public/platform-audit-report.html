2 القدرات الستة الجديدة المنقولة والمطورة بالكامل من Cyber-AI

1. Active Form & XSS Fuzzer

مفعل

فاحص استكشافي ذكي يستخرج كل وسوم <form> وحقول الإدخال، ويقوم بإرسال طلبات POST/GET حقيقية بحقن Canary تجريبي آمن، ويكتشف ارتداد الأكواد غير المعقمة في الـ DOM فوراً (CWE-79).

2. Raw TLS Socket & Cipher Audit

مفعل

فحص مباشر عبر Raw TCP Socket على بورت 443 يفحص صلاحية شهادة الـ SSL بدقة، اسم المصدر (Issuer)، الشهادات ذاتية التوقيع (Self-signed)، ويكتشف البروتوكولات القديمة (SSLv3, TLS 1.0, TLS 1.1).

3. Server-Side Template Injection (SSTI)

مفعل

حقن متجهات حسابية مثل {{7*7}} و ${7*7} في كل المعاملات لاكتشاف ما إذا كان السيرفر يقوم بمعالجة قوالب ديناميكية خبيثة تؤدي إلى تنفيذ أوامر عن بعد (CWE-1336).

4. LFI & OS Command Injection

مفعل

فاحص اختراق المسارات وقراءة الملفات الحساسة (Path Traversal) والتأكد من عدم استجابة السيرفر لأوامر الـ Shell وحمايته من تسريب ملفات النظام مثل /etc/passwd (CWE-22 / CWE-78).

5. Cloud Storage Leaks Recon

مفعل

استطلاع وتخمين الباكيتس السحابية المكشوفة التابعة للدومين (AWS S3, Google Cloud Storage, Azure Blob) والتأكد مما إذا كانت مفتوحة للقراءة العامة دون صلاحيات (CWE-732).

6. Multi-Platform Server Patches

مفعل

إمكانية تحميل ونسخ ملفات كونفج جاهزة ومباشرة لحماية خوادم الإنتاج بضغطة زر لكل من: Nginx, Apache (.htaccess), Caddy, Express.js (Node), و Django (Python).
