1️⃣ محركات الفحص الهجومي الديناميكي (DAST & Active Probing Engines) 14 أداة ومحرك نشط
⚡ Active Form XSS Fuzzer
form-fuzzer.service.ts
يقوم باستخراج نماذج الـ HTML وحقول الإدخال (<input>, <textarea>)، وحقن Canaries تشخيصية ذكية (sential_probe_xss"'><canary>) عبر طلبات GET و POST وفحص الارتداد غير المشفر بالـ DOM.
Active Fuzzing CWE-79 / OWASP A03 Node.js DOM Parser
🔒 Raw SSL/TLS Socket Auditor
ssl-cipher-auditor.service.ts
يفتح اتصال Raw TCP Socket مباشر عبر المنفذ 443 ويفحص شهادات X.509، الصلاحية بالأيام، الموقعة ذاتياً، ويختبر تفاوض الاتصال بالبروتوكولات الضعيفة (SSLv3, TLS 1.0, TLS 1.1).
Raw Socket 443 CWE-326 / CWE-295 Node tls/net
🧩 Server-Side Template Injection
ssti-auditor.service.ts
يحقن تعبيرات رياضية تقييمية مثل {{7*7}} و ${7*7} في معلمات الروابط مع إجراء **Baseline Verification** مسبق لمنع أي إيجابيات كاذبة.
Active Injection CWE-1336 / CWE-94 Baseline Zero-FP
📁 LFI & Safe OS Command Auditor
lfi-cmd-auditor.service.ts
يفحص تخطي المسارات للملفات الحساسة (/etc/passwd, win.ini) وحقن كواشف الـ Echo الآمنة تماماً بدون تخريب السيرفر أو تسريب بيانات.
Safe Canary Echo CWE-22 / CWE-78 Regex Signature
☁️ Cloud Storage Bucket Recon
cloud-leak-auditor.service.ts
يولد أسماء الحاويات السحابية بناءً على النطاق والاسم التجاري للمنظمة، ويفحص القراءة العامة لسلات **AWS S3**, **Google Cloud Storage**, و **Azure Blob Storage**.
Multi-Cloud HEAD CWE-200 / CWE-538 S3 / GCS / Azure
🆔 BOLA / IDOR Tampering Auditor
idor-auditor.service.ts
يرصد المعرفات الرقمية المتسلسلة في مسارات الـ APIs ويقوم بتجربة المعرف التالي (id + 1) لفحص هل يرجع السيرفر كود 200 وبيانات مستخدم آخر دون تدقيق للصلاحيات.
Path Tampering CWE-639 / OWASP API1 Session Prober
🚪 Access Control & Bypass Auditor
access-control-auditor.service.ts
يفحص لوحات الإدارة غير المحمية (/admin, /dashboard)، وتخطي الـ Reverse Proxy عبر رؤوس X-Original-URL و X-Rewrite-URL وكشف قواعد البيانات المتروكة.
Header Bypass Probe CWE-306 / CWE-285 Route Dictionary
🕸️ GraphQL & WebSocket Auditor
graphql-auditor.service.ts
يفحص مسارات GraphQL لاكتشاف فتح خاصية الـ Introspection وسحب الـ Schema الكاملة، وتجربة تخطي الـ WebSocket handshake دون توكنات تحقق.
Introspection Query CWE-200 / CWE-284 GraphQL AST
🔑 JWT Token Security Auditor
jwt-auditor.service.ts
يفحص توكنات JWT ويختبر ثغرة التوقيع الفارغ (alg: none)، ضعف المفاتيح السرية الشائعة، التوكنات منتهية الصلاحية، وفك التشفير لكشف البيانات الحساسة المضمنة بالـ Payload.
Cryptographic Audit CWE-347 / CWE-327 JWT Signature
🧪 Prototype Pollution Prober
prototype-pollution.service.ts
يرسل حمولات اختبار الـ Prototype Pollution عبر معلمات الـ JSON والـ Query parameters مثل __proto__[sential_polluted]=1 ويرصد استجابة السيرفر وتلوث الكائنات.
Object Injection CWE-1321 JSON Payload Prober
🌐 SSRF & Cloud Metadata Hunter
ssrf-auditor.service.ts
يفحص معلمات الروابط وحقن عناوين الـ Loopback والـ Metadata السحابية مثل http://169.254.169.254/latest/meta-data/ لاكتشاف تسريب بيانات الـ IAM والتفويض.
Metadata Traversal CWE-918 / OWASP A10 AWS / GCP / Localhost
📡 OAST Out-of-Band Callback Server
oast.service.ts
محرك التفاعل الخارجي لرصد الثغرات العمياء (Blind SQLi, Blind SSRF, Blind XSS) عن طريق رصد نداءات الـ DNS والـ HTTP الراجعة لسيرفر الاستماع الخاص بالمنصة.
Out-of-Band Listener CWE-918 / CWE-89 DNS / HTTP Canaries
🎯 Nuclei & OWASP ZAP Adapters
nuclei.adapter.ts / zap.adapter.ts
محولات قياسية متوافقة مع مخرجات ZAP DAST وقوالب Nuclei المفتوحة، توفر مصفوفات فحص للثغرات الشائعة والـ CVEs المنشورة حديثاً.
DAST Standards CWE Multi-family Template Scanner
🛰️ Port Scanner & CMS Fingerprinter
whatweb.adapter.ts / wpscan.adapter.ts
مسح المنافذ القياسية (21, 22, 80, 443, 3000, 8080)، استخراج بصمات السيرفرات (Nginx, Apache, IIS)، وكشف أنظمة إدارة المحتوى وقوالب WordPress وإصداراتها.
Reconnaissance CWE-200 Socket / HTTP Banners
2️⃣ محركات فحص الكود المصدري الساكن (SAST & Semantic Analysis) 970+ قاعدة ومعالجة AST
📚 SentinelAI 970+ CWE Knowledge Base
knowledge-base.service.ts
قاعدة بيانات ضخمة مدمجة تحتوي على 970 تعريف تفصيلي للضعف الأمني، تقدم لكل ثغرة: الوصف الدقيق، مسار الاستغلال، الأثر التشغيلي، وكود الترقيع الموصى به رسمياً.
Knowledge Engine 970 CWE Definitions JSON Micro-DB
🔍 AST Semantic & Taint Tracking (CodeQL)
codeql.adapter.ts / ai-reasoning.service.ts
تحليل شجرة البنية المجردة (AST) وتتبع مسار تدفق البيانات من المدخلات غير الموثوقة (req.query, req.body) وصولاً إلى دوال التنفيذ الخطرة (Sinks) مثل eval() و exec().
Taint Analysis CWE-20 / CWE-78 / CWE-89 Source-to-Sink
⚡ Semgrep AST Pattern Matcher
semgrep.adapter.ts
مطابقة الأنماط البرمجية الخطرة داخل كود JavaScript, TypeScript, Python, و PHP، لاكتشاف استخدام دوال التشفير الضعيفة مثل Math.random() و md5.
AST Regex / Patterns CWE-330 / CWE-327 Polyglot Rules
🗝️ Gitleaks Credential & Secret Hunter
gitleaks.adapter.ts
فحص الإنتروبيا (Shannon Entropy) والتعبيرات النمطية المتقدمة لكشف مفاتيح AWS، وتوكنات GitHub (ghp_)، ومفاتيح Stripe، والشهادات الخاصة داخل ملفات الكود والـ Git History.
Secret Detection CWE-798 / CWE-532 High-Entropy Regex
3️⃣ فحص سلاسل التوريد والاعتماديات (SCA & Cloud IaC Layer) أمان المكتبات والـ Containers
📦 npm-audit & OSV Live Scanner
npm-audit.adapter.ts / osv-scanner.adapter.ts
مطابقة ملفات الاعتماديات (package.json, package-lock.json) مع قاعدة بيانات الثغرات المفتوحة OSV وقاعدة بيانات أمان GitHub لرصد الـ CVEs المنشورة.
Dependency Audit CWE-1395 / OWASP A06 OSV API Sync
🛡️ Trivy & Checkov (IaC & Containers)
trivy.adapter.ts / checkov.adapter.ts
فحص ملفات Dockerfile وتكوينات الـ Infrastructure as Code (Terraform, Kubernetes, CloudFormation) لرصد التكوينات الخاطئة وتشغيل الحاويات بصلاحيات الـ Root.
IaC Misconfiguration CWE-732 / CWE-250 Container Security
4️⃣ محركات الترقيع الآلي وحماية السيرفرات (Remediation & Hardening Layer) توليد كود إنتاجي فوري
⚙️ Multi-Platform Server Hardening Generator
platform-patch.service.ts
يولد تلقائياً قواعد ترقيع وتكوينات حماية جاهزة للتحميل الفوري لخمس منصات رئيسية: **Nginx** (nginx.conf), **Apache** (.htaccess), **Caddy** (Caddyfile), **Express.js** (helmet), و **Django** (settings.py).
Auto Config Generator Server Hardening 5 Platforms Ready
🔧 In-Place Code Remediation Engine
git-remediation.service.ts
يولد Unified Diff قياسي بتنسيق Git، ويقوم بتصحيح الأكواد المصابة تلقائياً على القرص لثغرات SQL Injection عبر Prepared Statements، و XSS عبر DOMPurify، و Command Injection عبر execFile.
Source Code Patch Git Unified Diff Automatic Fix

findings-deduplication.service.ts

Data Normalization Fingerprint Hashing
📐 Mathematical CVSS v3.1 Calculator
cvss-calculator.service.ts

Official Standard FIRST Equations
🤖 AI Security Copilot (On-Device NLP)
ai-chat.routes.ts
مساعد ذكي ثنائي اللغة متصل بالمعرفة الأمنية الحية وسياق الفحص يشرح الثغرات، يجيب على الأسئلة التقنية، ويوضح خطوات الاستخدام والترقيع الفورية.
Conversational AI Bilingual AR / EN

scripts/export-pdf.js
